# Manual Checklist — WebSocket Ping/Pong

以下内容不在母版中伪造成普通单测，接入真实服务后由人工或专项环境执行：

- [ ] staging 网关使用真实认证凭据建立 `/ws` 连接，确认合法用户成功、过期/无权限身份拒绝。
- [ ] 在真实浏览器/客户端通过网关验证 Origin 白名单、Cookie/Header 传递和握手失败状态。
- [ ] 两个服务实例同时运行，验证连接、消息和临时路由是否满足项目的单实例/粘性路由约束。
- [ ] 在接近容量的连接数和消息频率下观察 CPU、内存、线程、连接数和拒绝指标。
- [ ] 注入网络抖动、断线重连和服务重启，确认不会产生重复业务副作用。
- [ ] staging 发布后验证 `/actuator/health`、readiness、`/ws` smoke test 和回滚限制。

每项记录环境、版本、时间、结果和证据；未执行写 `NOT_RUN`，不要写成 PASS。
